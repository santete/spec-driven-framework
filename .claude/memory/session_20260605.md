## Decisions made
- **No async migration**: CLI stays sync. LLM work done by Claude Code subagents (blocked→resume pattern). Avoids 25-file breaking change.
- **Bootstrap mode for testing**: VITEST=true or KEYSTONE_BOOTSTRAP=1 uses Phase 0 templates. Production uses LLM validate-only mode.
- **S3 ADR based on classification**: Not baseline existence. Additive changes don't need ADR.
- **Loader skips _* dirs**: specs/_drafts, specs/_test-*, specs/_examples all excluded.
- **Generated code excluded from tsc/vitest**: tsconfig.json excludes src/generated/ and tests/generated/. Vitest config excludes tests/generated/.
- **G7 drift = warn not fail**: Within same run, version mismatches are regeneration artifacts, not real drift.
- **S8 git add -f for gitignored paths**: src/generated/, .keystone/ need force-add.

## Gotchas discovered
- **S6 import paths**: Generated test at tests/generated/auth/auth.spec.ts must import with ../../../ (3 levels), not ../../ (2 levels). Fixed.
- **Vitest discovers generated tests**: tests/generated/ picked up by tests/**/*.spec.ts glob. Fixed with exclude in vitest.config.ts.
- **S8 commits in dry-run**: StationContext had no dryRun flag. Fixed by threading from CLI.
- **Auto-commit pollution**: 10 bootstrap dry-run tests created real git commits. Fixed dry-run + cleaned history.
- **E2E test ordering flake**: S5 test creates specs/sdd/ in real repo, E2E fixture copies it. Rare, passes on retry.
- **S0 IQ1 requires refines**: New REQs need `refines: [FEAT-*]`, not just `depends_on`.
